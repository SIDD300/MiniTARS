# MiniTARS

## A Modular Physical AI Assistant

MiniTARS is a modular physical AI assistant designed to provide
interactive assistance through voice, AI, vision, display, and
controlled robotic actions.

## Initial Use Case

College reception and visitor assistance.

## Technology Stack

- Python
- AI/LLM
- Speech-to-Text
- Text-to-Speech
- Java Spring Boot
- MySQL
- React
- Raspberry Pi
- ESP32 (optional hardware controller)
- Camera
- Servo motors
